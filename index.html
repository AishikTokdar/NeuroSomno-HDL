Architecture and commands

The active FCN is 784 -> 30 -> 30 -> 10 -> 2, with ReLU, ReLU, sigmoid and linear outputs. Class 0 is normal; class 1 is apnea. The software CNN and standalone streaming blocks are separate.

python -m pip install -r python_pipeline/requirements.txt
python scripts/verify_project.py
python scripts/verify_project.py --synthesize
python python_pipeline/validate_memory.py --checkpoint models/fcn_model.pt

Verification needs Icarus Verilog, Node.js and GCC on PATH. Add Yosys for synthesis. No board is required for these checks. See README and interface documentation.
