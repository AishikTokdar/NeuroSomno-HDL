Target FPGA Board & Hardware Primitives

Detailed specs of the Xilinx ZedBoard (Zynq XC7Z020-CLG484-1) evaluation platform.

LUT
Look-Up Tables (LUT6)
53,200 total LUTs on the Zynq-7000 fabric. 6-input LUTs emulate any 6-variable boolean logic function, 64-bit shift registers, or Distributed RAM (LUTRAM). Used in Layer 2–4 weight memory and Sigmoid ROM LUTs (5,120 LUTs).
DSP
DSP48E1 Multiplier Slices
220 total DSP slices. Each DSP48E1 slice contains a high-speed 25×18 signed multiplier and 48-bit accumulator. The design uses 160 DSPs (2 per neuron due to unsigned port casting; reducible to 80 DSPs by adding signed declarations).
RAM
Block RAM (BRAM36 / BRAM18)
140 total 36Kb Block RAMs (or 280 18Kb RAMB18E1 blocks). Dedicated dual-port memory cells embedded in silicon. Layer 1 uses 15 BRAMs (0.5 RAMB18 per neuron) to store 30×784 16-bit weight parameter arrays.
STA
Static Timing Analysis & Clocking
Target PL clock frequency of 100 MHz (10.00 ns period) driven via MMCM/PLLE2. Pipelined 3-stage MAC execution achieves a Worst Negative Slack (WNS) of +4.156 ns ($F_{max} \approx 171.12\text{ MHz}$).

Automated & Manual Execution Guide

Run the full pipeline using automated launcher scripts or step-by-step commands.

Automated Launcher Scripts (Linux, macOS, Windows) 
# Linux / macOS / WSL / Git Bash:
chmod +x run_all.sh
./run_all.sh

# Windows PowerShell:
powershell -ExecutionPolicy Bypass -File .\run_all.ps1

# Windows Command Prompt (CMD):
run_all.bat
Icarus Verilog Open-Source CLI Simulation 
# Compile RTL and Testbench using Icarus Verilog:
cd hardware/mif
iverilog -g2012 -I ../rtl -o sim_top ../rtl/*.v ../tb/tb_top_sim.v

# Run the VVP simulator executable:
vvp sim_top

AXI-Lite Register Interface Map

Interfacing memory-mapped registers for host control and status monitoring.

Index Address Offset Access Name Bitfield & Description
0 32'h00 R/W REG_CTRL Bit [0]: Soft Reset (1=Reset), Bit [1]: Start Inference (1=Trigger)
1 32'h04 R/W REG_LAYER Bits [3:0]: Target Layer ID (1 to 4)
2 32'h08 R/W REG_NEURON Bits [5:0]: Target Neuron ID (0 to 29)
3 32'h0C R/W REG_WADDR Bits [11:0]: Weight Memory Address offset
4 32'h10 R/W REG_WVAL Bits [15:0]: 16-bit signed Q3.13 weight parameter value
5 32'h14 R/W REG_BVAL Bits [15:0]: 16-bit signed Q3.13 bias parameter value
6 32'h18 W REG_WEN Bit [0]: Weight write strobe
7 32'h1C W REG_BWEN Bit [0]: Bias write strobe
8 32'h20 R REG_NNOUT Bits [3:0]: Final Argmax output (0 = Normal, 1 = Apnea)
9 32'h24 R REG_STATUS Bit [0]: Done Flag, Bit [1]: Interrupt Pending (`intr` pin state)
