# Memory Initialization Files (MIF)

This folder is the target directory for all weight, bias, activation table, and test simulation files generated by the MATLAB script [`extract_weights.m`](../../matlab_preprocessing/extract_weights.m) or Python script [`python_pipeline/export_weights.py`](../../python_pipeline/export_weights.py).

---

## File Overview

| Filename Pattern | Type | Contents |
| :--- | :---: | :--- |
| **`w_X_Y.mif`** | Input File | Quantized weights for Layer `X` (1 to 4) and Neuron `Y` (0 to `numNeurons-1`). |
| **`b_X_Y.mif`** | Input File | Quantized bias parameter for Layer `X` and Neuron `Y`. |
| **[`sig_rom.mem`](sig_rom.mem)** | Lookup ROM | Precomputed Sigmoid activation table containing 1024 binary values. |
| **[`test_data.txt`](test_data.txt)** | Test Vectors | Test input sequences (30 samples, 784 lines each of 16-bit binary values). |
| **[`test_labels.txt`](test_labels.txt)** | Ground Truth | Expected labels for the 30 test samples (4-bit binary values). |

---

## Format Specifications

All files are structured as plain text where each line represents a 16-bit binary string representing a signed two's complement fixed-point value:

*   **Format:** `[1 sign bit][2 integer bits][13 fraction bits]` (Q3.13 fixed-point representation).
*   **Usage in RTL:** Loaded automatically during simulator initialization using:
    ```verilog
    initial begin
        $readmemb("w_1_0.mif", mem);
    end
    ```

> [!WARNING]
> Keep all generated files within this folder. Do not manually edit the contents of these files, as it will disrupt the binary encoding alignment and cause simulation mismatches.
